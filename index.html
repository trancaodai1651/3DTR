Hướng dẫn

Quyền truy cập và luồng dữ liệu

01

Đăng nhập Google

Website nhận ID token từ Google Identity Services. Không lưu mật khẩu và không có client secret ở trình duyệt.

02

Kiểm tra quyền file

Apps Script xác minh token rồi kiểm tra tài khoản là Owner, Editor hay Viewer của Google Sheet.

03

Ghi dữ liệu an toàn

Chỉ Editor được gửi bản ghi. Viewer nhận phản hồi từ chối ở API dù có tự mở DevTools hay sửa giao diện.

04

Công thức tự chạy

Dữ liệu được ghi vào đúng cột nhập. Các cột doanh thu, COST và lợi nhuận vẫn do công thức trong Sheet tính.

Triển khai

Hoàn tất kết nối trong 4 bước

  1. Nhập workbook 3DTR vào Google Drive và chuyển thành Google Sheets.
  2. Triển khai apps-script/Code.gs dưới dạng Web app chạy bằng tài khoản chủ file.
  3. Tạo OAuth Web Client, thêm URL GitHub Pages vào Authorized JavaScript origins.
  4. Điền Client ID và URL Web app trong config.js, rồi tải lại trang.
